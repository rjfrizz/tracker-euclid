# EUCLID synth definitions

Definition files for the EUCLID Synth page (Shift + Params on the Original,
Instr on the Tracker+): one `.syn` file per hardware synth. Copy them to
`Synths/` on the Tracker's SD card. The format is described at the top of
`core/source/euclid/synthDef.h`.

On the Synth page, edits go out as you make them. Insert sends the whole
patch; Shift + Insert gets the synth's patch (for definitions with
`request` and `dump` lines).

| File | Synth | Source |
|---|---|---|
| `TX81Z.syn` | Yamaha TX81Z voice edit buffer | Generated by `tools/edisyn_tx81z.py` from Edisyn's `Yamaha4Op.java` |
| `D110.syn` | Roland D-110 temporary tone of a part (1-8) | Generated by `tools/edisyn_d110.py` from Edisyn's `RolandD110Tone.java` |

To regenerate a file, fetch Edisyn (https://github.com/eclab/edisyn) and run
its script, e.g.

    python3 tools/edisyn_tx81z.py path/to/edisyn/synth/yamaha4op/Yamaha4Op.java > TX81Z.syn
    python3 tools/edisyn_d110.py path/to/edisyn/synth/rolandd110/RolandD110Tone.java \
        path/to/edisyn/synth/rolandd110/RolandD110Multi.java > D110.syn

## Setting up the TX81Z

- UTILITY > Sys Info: AVAIL. Otherwise it plays notes but ignores edits and
  dump requests.
- UTILITY > receive channel: a channel number (not OMNI), matching Device on
  the Synth page. It's also the channel the notes must use.
- Single (Play) mode. In Performance mode the edits may not be heard.
- Voice > Memory picks a stored voice (I01 to D32), the way Edisyn does it
  (it points program change 128 at the voice, presses PLAY remotely and
  sends program change 128), then gets the voice so the page shows it.
- The edits change the edit buffer: STORE on the TX81Z keeps them.

## Setting up the D-110

- Device on the Synth page is the D-110's unit number less 16: unit 17 (the
  usual) is Device 1.
- Part picks which of the D-110's 8 parts the channel edits. Auto (the
  default) follows the channel's MIDI channel, the D-110's default layout:
  channel 2 is Part 1, 3 is Part 2 ... 9 is Part 8. On other MIDI channels
  Auto shows "none" and nothing is sent; pick a part number to override.
- Memory Protect OFF, and (Edisyn's notes) Overflow OFF: older ROMs fail
  dumps otherwise. Edisyn recommends ROM 1.10 or later; it had a report of
  real-time edits crashing a 1.06 ROM.
- The Part group picks the tone the part plays (Tone group, Tone number)
  and its level, pan, key shift and so on. Choosing a tone gets it, so
  the other groups show the new tone.
- Edits change the part's temporary tone. Write it on the D-110 to keep it.
- Insert sends all 236 parameters one by one, which takes about 7 seconds.
